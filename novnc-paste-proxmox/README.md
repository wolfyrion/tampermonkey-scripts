# noVNC Paste for Proxmox

Types your PC's clipboard into a VM through the Proxmox noVNC console. That's useful for VMs without clipboard sharing.

**[Install](https://raw.githubusercontent.com/wolfyrion/tampermonkey-scripts/main/novnc-paste-proxmox/novnc-paste-proxmox.user.js)**

## Usage

1. Open a VM's console in the Proxmox web UI. The script runs on any host on port 8006.
2. Switch **PASTE ON**.
3. Right-click the console. Your clipboard is typed into the VM.
