# Steam Ownership Highlighter

Adds Steam ownership and wishlist badges on SteamGifts, r/GameDeals, r/FreeGameFindings, GG.deals, IsThereAnyDeal, Humble Bundle, Fanatical, IndieGala and Green Man Gaming. On stores that don't show Steam app IDs, it matches games by name. Hover a game to see Steam and ITAD prices. It can also filter out rows for games you already own.

**[Install](https://raw.githubusercontent.com/wolfyrion/tampermonkey-scripts/main/steam-ownership-highlighter/steam-ownership-highlighter.user.js)**

## Setup

- Log in to Steam in the same browser. The script reads your owned and wishlisted games from the Steam store.
- For ITAD prices, enter an IsThereAnyDeal API key in the script's settings. This is optional.
- Settings are in the Tampermonkey menu while you're on a supported site.
